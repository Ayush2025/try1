Can you explain the chain rule in calculus?

2 minutes ago

The chain rule is a fundamental rule in calculus for finding derivatives of composite functions. If you have a function f(g(x)), the derivative is:

(f ∘ g)'(x) = f'(g(x)) · g'(x)

In simple terms: differentiate the outer function, multiply by the derivative of the inner function.

Example: If f(x) = (3x + 1)², then:
• Outer function: u² where u = 3x + 1
• f'(u) = 2u = 2(3x + 1)
• Inner function: g(x) = 3x + 1, so g'(x) = 3
• Final answer: f'(x) = 2(3x + 1) · 3 = 6(3x + 1)
